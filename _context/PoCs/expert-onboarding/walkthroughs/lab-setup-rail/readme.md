# L1 — Setup Rail

**Route:** `/expert-onboarding/lab/setup-rail`  
**Mobbin:** `_context/mobbin/Apps/web/onboarding/remote.com Web Onboarding` (screens 0–24)  
**Implementation:** React · Hybrid

## Pattern

Vertical left **step rail** with done/active/upcoming states (Remote.com). Main stage collects practice → offer → identity. Final screen = **dashboard todo cards** (photos, Stripe, compliance, 2FA).

## Spine (5 phases)

1. Practice — specialty, country, city  
2. First offer — session title, duration, price  
3. Identity — name, headline  
4. Handoff — checklist (no inline compliance)

## Aesthetic

B2B utilitarian · slate-900 rail · emerald checkmarks
